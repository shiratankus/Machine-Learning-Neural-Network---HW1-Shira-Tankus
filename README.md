# Machine-Learning-Neural-Network---HW1-Shira-Tankus
Getting the data
The dataset v1-v2_gratings.zip (~143 MB) is stored with Git LFS. 
⚠️ The green Code → Download ZIP button does not include the real data file — it only contains a small placeholder.

Use one of these options instead:

## Option 1: Download the data file directly

Click on v1-v2_gratings.zip in the file list above.
Click the Download raw file button (download icon, top right).
Save it in the same folder as the notebook.

## Option 2: Clone with Git LFS

git lfs install

git clone https://github.com/shiratankus/Machine-Learning-Neural-Network---HW1-Shira-Tankus.git

cd Machine-Learning-Neural-Network---HW1-Shira-Tankus

(If the zip is only ~1 KB after cloning, run git lfs pull.)

## Option 3: Open in GitHub Codespaces 
Click Code → Codespaces → Create codespace on main. The data file is downloaded automatically.

**Running the notebook**

Make sure v1-v2_gratings.zip is in the same folder as the notebook (the notebook unzips it automatically).

Open HW 1.ipynb in Jupyter, VS Code, or Codespaces.

Run all cells (Run All).
